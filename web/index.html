Model architecture

pts = percentage points of SOH. An error of 0.50 pts means the prediction was off by half a point of SOH (e.g. 91.5% predicted vs. 92.0% actual) — written this way rather than "%" so it isn't mistaken for a relative error. R² is the share of this cell's SOH variation the model explains: 1.0 is perfect, 0 is no better than always guessing the cell's mean. It is computed over the predictions revealed so far, so it moves as the run progresses.

About this model

Data

VL coin cells (4): Panasonic VL1220 / VL2020 form factors cycled by Neware at 0.2C, room temperature / 40°C, ~100 cycles each with ~30s sampling. Cycle 1 is excluded: it carries an extra leading rest step and inconsistent discharge capacity on at least one cell — a test-setup artifact, not real aging.

Oxford pouch cells (8): 0.74 Ah pouch cells (cells 1_1–1_8), CCCV cycling at 40°C, 45–78 cycles each with per-sample voltage/current/temperature logging. Charge/discharge summary features (durations, CV tail, coulombic efficiency) are derived from the raw current/voltage/phase traces via a purpose-built adapter, since this dataset has no discrete step-type labels the way the Neware exports do.

SOH definition

VL cells: SOH(cycle) = discharge capacity(cycle) / Cref × 100, where Cref is the peak discharge capacity observed in cycles 2–11 (post break-in/formation) — these coin cells show a real capacity rise during early formation cycles before fade begins.

Oxford cells: SOH(cycle) = capacity(cycle) / rated capacity (0.74 Ah) × 100 — the dataset's own established convention; no formation rise is present so no separate reference-capacity step is needed.

Model & validation

A small residual LSTM (16 hidden units) predicts next-cycle SOH from a 10-cycle window of summary features (capacity, coulombic efficiency, step durations, temperature, voltage), conditioned on C-rate/temperature/form-factor. Validated with leave-one-cell-out cross-validation across every cell in the pool. All inference runs locally in your browser via ONNX Runtime Web; no data leaves your device.
